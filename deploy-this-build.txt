GQDS HELPER DASHBOARD v6.0.5.15 — CLEARER ADMIN OVERVIEW

This preview candidate separates the admin Home screen into:
- MY ACTIVITY — owner weekly/monthly retained earnings, shift count and hours.
- HELPER ACTIVITY — helper shifts involving the owner, payments made this week and outstanding helper pay on those shifts.
- COMBINED VIEW — weekly summary of the owner's recorded shifts and the related helper payment position.

Presentation-only. No formulas, existing calculations, Notion records, API endpoints, permissions or helper-facing screens changed. The helper metrics are not an all-staff payroll report. The package was built from the available v6.0.5.14 source tree; its identity against the currently published production bundle has not been independently verified. Treat as preview-only until the production baseline is confirmed.

DEPLOYMENT
- Deploy the full ZIP to a Netlify Deploy Preview first; it contains Netlify Functions.
- Preserve all current Netlify environment variables and production deployment.
