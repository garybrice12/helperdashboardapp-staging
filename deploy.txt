SOURCE PACKAGE FOR THE EXISTING GITHUB-CONNECTED NETLIFY PROJECT.
Apply these files to the existing repository root and let the connected Netlify build run. This package includes Netlify Functions, so use the build pipeline rather than a static drag-and-drop deploy. It replaces the root dashboard and keeps the in-dashboard Helper Assistant at #ask-ai.
Before testing, ensure OPENAI_API_KEY and NOTION_TOKEN are configured in Netlify environment variables. See AI-SETUP.txt for the AI key.
The existing production URL and helper-facing links should remain unchanged until the staged build has been tested and explicitly approved for promotion.

LIVE DATA UPDATE
- GET /api/dashboard-data reads directly from the live Notion data sources on each page load.
- This build does not use a POST update endpoint or Netlify Blobs as the source of truth. Shift and earnings updates must be made in the existing Notion databases.
Live Notion data:
- Required Netlify environment variable: NOTION_TOKEN (private Notion integration token with access to both the Earnings log (new) and Work Planner — Shifts data sources).
- Optional NOTION_EARNINGS_DATA_SOURCE_ID defaults to the Earnings log (new) data source.
- Optional NOTION_SHIFTS_DATA_SOURCE_ID defaults to the Work Planner — Shifts data source.
- Redeploy after changing environment variables. Never put NOTION_TOKEN in browser HTML or commit it to Git.
